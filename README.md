# BetQC, données en direct

Données publiques de [BetQC](https://betqc.netlify.app), mises à jour aux 10 minutes par le robot
(`.github/workflows/robot.yml`).

- `public/` : fichiers lus par le site (occasions, paris fictifs, profil des bookmakers, cotes par match).
- `live/` : registre des paris fictifs, journal des balayages et cotes archivées (un fichier par balayage, 21 jours).

Aucun conseil de pari. Les cotes changent : vérifie toujours chez le bookmaker.
